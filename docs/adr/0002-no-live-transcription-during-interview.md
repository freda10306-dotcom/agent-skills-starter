# 0002 訪談當下不做即時轉錄

Status: Proposed

## 決定

- 訪談當下只靠主訪手動勾選訪綱和副訪的文字筆記。AI 比對筆記和訪綱，產出漏問提示。
- 錄影在訪談結束後才轉錄。完整逐字稿再對照訪綱，產出漏問報告。

## 否決的選項

- **全即時串流轉錄**：中文口語、多人搶話、中英夾雜，在兩個月內要做到夠穩的風險太高。即時串流也很難配合「本機轉錄」（0001）的硬體限制。
- **全事後處理、取消當下的漏問檢核**：brief 改變 2 要求在「結束訪談」前就能補問，事後才知道漏問就來不及補了。

## 為什麼

漏問檢核只需要「哪些題問過了」的訊號，不需要完整的逐字稿。把當下和事後分開，即時的部分只剩文字比對。事後的漏問報告同時是漏問提示的評估基準，可以算出「漏問檢核正確率」。
