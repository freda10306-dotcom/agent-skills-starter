# 0003 遮蔽後的逐字稿要經研究員放行才送外部 LLM

Status: Proposed

## 決定

- 遮蔽時不確定是不是個資，一律遮掉。
- 遮蔽後的逐字稿要等研究員看過、按下放行，系統才會送到外部 LLM。沒有放行紀錄就不送出。

## 否決的選項

- **自動遮蔽後直接送出**：召回率 95% 代表每 20 筆個資可能漏 1 筆，一旦漏掉就是不可逆的外流。
- **只多遮、不人工放行**：多遮可以降低漏遮的機率，但沒辦法保證不漏。

## 為什麼

送出外部是不可逆的動作，所以加一道人工閘門。這跟 brief「研究員確認後才算數」的精神一致。代價是研究員多一個步驟，多遮也會讓摘要品質下降，這兩個代價都要在評估報告裡量化。
